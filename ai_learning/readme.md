# AI learning (RonkBonk)

- `ai_logic.js` — heuristic bots for all difficulties; Elite loadouts from tournament ranks.
- `elite-brain.js` — **play-only** forward pass for Elite (invincible). No training.
- `elite-pretrained.json` — weights from full-game ultimate training (~42k games).
- `elite-trained-stats.json` / `elite-all-combos.json` — reports only (not required at runtime).

Easy / medium / hard never use the net.
